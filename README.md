# 🚀 Repositorio base del Curso de Introducción a React.js en Platzi

Este repositorio está dedicado al estudio, práctica y desarrollo del [Curso de Introducción a React.js](https://platzi.com/reactjs).

---

## 🌿 Estructura de Ramas

A continuación se detalla el propósito de cada rama disponible en el repositorio:

### 1. `main` (o `master`)

- **Descripción:** Rama principal del repositorio. Contiene el proyecto realizado en el curso.

---

## ⚙️ Cómo empezar a trabajar con el repositorio

Si deseas clonar este repositorio y explorarlo, sigue estos pasos en tu terminal:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/ediiidev/curso-reactjs-platzi-2026.git](https://github.com/ediiidev/curso-reactjs-platzi-2026.git)
   cd curso-reactjs-platzi-2026
   npm install
   npm run start
   ```
